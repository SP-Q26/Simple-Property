# ROI & scale · Deposit Desk

## Unit economics

- **High margin:** static Vercel + Stripe · no per-packet COGS
- **Primary model (2026 dive):** **per-turn** ~$29/move · ~$49/tenancy — pass-through like screening; see `docs/PRICING_DIVE_PER_TURN.md`
- **Subscription upsell:** $22/mo · $99/yr when **≥3–4 turns/yr** across ≤4 doors
- **Legacy note:** subscription-only ACV math understated seasonal buyers — turn mix improves conversion before MRR
- **One saved dispute** >> any single turn fee — message for conversion, not feature count
