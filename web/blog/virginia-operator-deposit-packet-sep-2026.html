Virginia · Simple Property Tools

Virginia security deposit packet checklist · small landlords

Itemize withholds, date surrender, and export before the return clock wins. Out-of-state mail on day forty-four without tracking is a common belt investor pain point.

Return default
45 days from surrender (keys back · unit vacant)
Statute label
Va. Code § 55.1-1226
Practice
One line per withhold · dated photos · proof of mail when you send balance

Before you print or email

  • Log surrender the day possession returns, not the lease end date on paper alone.
  • Match move-in notes to move-out withhold descriptions.
  • Archive the PDF export and tracking number in operator logs.

When something already went wrong, start with our Virginia operator pain guide.
